# Codex phase checklist and stop conditions

- [ ] Read repository rules, provided docs, current source, all existing commits/changes.
- [ ] Record actual route + component + Sanity + DNS/deployment inventory.
- [ ] Run baseline `npm run build` and project lint/test (if available), record issues rather than hiding them.
- [ ] Create audit and status matrix with KEEP, REWRITE, MOVE, MERGE, RETIRE, INVESTIGATE.
- [ ] Repair broken links, build errors, inaccurate naming, premature PAVO/artist claims without destructive rewrites.
- [ ] Implement SIRYUS parent hero/minimal nav/four cards with correct URLs and no broken links.
- [ ] Keep each brand's visual system independent and apply its own real logos.
- [ ] Implement A.M with accurate roster and complete music/project/insight archive.
- [ ] Implement ARC. Creatives with its distinct journal, events, community, DSP, newsletter, supporters and Sanity.
- [ ] Implement SIGNAL. with Paths identity, **square period**, red/graphite/warm stone, and storytelling-led narrative.
- [ ] Catalog all media licenses/credits, optimize images, accessible interaction/motion.
- [ ] Migrate CMS content and SEO route by route; test old/new routes.
- [ ] Verify Cloudflare Pages previews and production requirements without changing email DNS.
- [ ] Test functional forms, event/article pages, navigation, responsiveness, screen readers, performance, analytics, consent and legal pages.
- [ ] Deliver screenshots, builds, test evidence, file changes and unresolved items for user review.

**Stop for approval** before deleting/replacing content, production cutover, DNS modification, releasing undisclosed artist information, publishing legal changes, or merging datasets.
