# PAVO Create logo asset package

This pack is for **PAVO Create**, the software company, **not** the PAVO social publishing product. The logo forms were vector-traced from the navy lockup image supplied on November 3, 2026. The white variant uses exactly the same geometry as the navy lockup, including the curved transparent separation line running through the ribbon symbol.

## Folders
- `svg/`: scalable vector artwork (paths traced from the supplied approved raster; no font files or font dependencies)
- `png/`: transparent PNG lockups, colored symbols, white and navy monochrome
- `jpg/`: flattened versions with suitable background colors (JPEG does not support transparency)
- `webp/`: additional lightweight web variants
- `favicon/`: icon-only branded square images (16–512px), favicon.ico, and white favicon variants
- `reference/`: the exact supplied navy image used for tracing

## Choosing files
- Dark website header: `svg/primary-white-transparent.svg` or `svg/primary-on-dark.svg`
- Light background: `svg/primary-navy-transparent.svg`
- One-color white on dark: `svg/monochrome-white-transparent.svg`
- One-color navy on light: `svg/monochrome-navy-transparent.svg`
- Social icon: `favicon/pavo-create-icon-512.png`
- Favicon: `favicon/favicon.ico` and 32/180/192/512px images

## Color palette
- Midnight Navy: `#061A30` (underlying supplied lettering is very dark navy)
- Ribbon Cyan: approximately `#00D8E4`
- Electric Blue: approximately `#087CFA`
- Cool Mist: `#E9F3FA`

## Production notes
The exact visual texture of the original raster lettering and gradient cannot be guaranteed from automatic tracing. These SVGs preserve the sourced outlines at high resolution, with smooth scalable fills and approximated gradients. Do not mistake these for the creator's original editable design file. Inspect at small size and before print/trademark production. The monochrome symbols use the exact same cutout geometry as the colored version.
