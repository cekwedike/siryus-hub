ID: uix15dy0m8

## Google AdSense
Publisher ID: pub-3731681794344166
Purpose: Displays ads on the site
to generate revenue. Ad units must
be created in the AdSense dashboard
and placement code added to pages
where ads should appear.
Dashboard: adsense.google.com
Note: The ads.txt file at
/public/ads.txt is required for
AdSense to verify site ownership.
